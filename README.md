## ⚡ What's the Vibe?

Yo! Welcome to the **Live Code Music** repo. 🎹💻

If you're a dev who loves electronic beats or a producer curious about the matrix, you're in the right spot. We're taking **Sonic Pi**, mixing it with some **Ruby magic**, and cooking up full-blown Techno, House, and Ambient tracks **LIVE**.

No pre-recorded loops. No fake stuff. Just raw code turning into sound waves. 🌊

### 🔥 Why You Need This
*   **Flex on your friends:** "I don't play instruments, I *program* them."
*   **Infinite Creativity:** Use loops, randomization, and AI logic to make music that never sounds the same twice.
*   **It's Free:** Open source tools, open source code.

## 🚀 How to Run This?
1.  Install **Sonic Pi**.
2.  Clone this repo: `git clone https://github.com/Shayanthn/livecodemusic.git`
3.  Open the `.rb` file from an episode.
4.  Hit **Run**.
5.  **Rave.** 🕺💃
